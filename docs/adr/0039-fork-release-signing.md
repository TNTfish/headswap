# 0039. 中文 Fork 的签名与更新来源

- 状态：采用
- 日期：2026-11-12
- 来源：用户要求为 TNTfish/headswap 发布 4.2.0 APK。

## 背景

中文 Fork 无法使用上游作者的 APK 签名密钥。自行编译的安装包需要由本 Fork
独立签名，Android 不允许它直接覆盖签名不同的上游安装包。

## 决定

- 使用本地生成并持久保存的独立 release 密钥，不提交或发布密钥及密码。
- 构建时通过 `HEADSWAP_RELEASE_PROPERTIES` 指定签名属性文件；未指定时沿用上游路径。
- 自动更新来源改为 `TNTfish/headswap`，避免下载签名不同的上游更新。
- APK 中保留 `versionName=4.2.0`、`versionCode=74`，首次 Fork 发布标签使用
  `v4.2.0-zh.1`，避免改变上游 `v4.2.0` 标签的含义。
- 附件名为 `headswap-4.2.0-zh.1.apk`，满足更新器的标签回退下载规则。

## 影响

以下卸载说明仅适用于旧包名 `v4.2.0-zh.1`。共存测试版改用独立包名，见 ADR 0041；签名密钥与更新来源的决定继续有效。

用户从上游版本切换时需要先卸载，应用设置会被清除。后续 Fork 安装包必须继续使用
同一密钥，并递增版本，才能覆盖安装并保留设置。
AA 连接使用的公开参考证书与 APK 签名密钥用途不同，参考证书按上游方式打包。
